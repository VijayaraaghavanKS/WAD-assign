Exercise 2: College Symposium Website using HTML + CSS

TechNova 2026 – College Symposium Website

Exercise 2 – College Symposium Website using HTML + CSS

1. Problem Description

Mini Project: College Symposium Website (HTML + CSS Only)
Scenario
  • Your college is organizing a national-level technical symposium called "TechNova 2026". The organizing committee wants a website to provide information about the event, showcase competitions, display schedules, and allow students to register online.
  • Design and develop a website using only HTML and CSS.
Website Structure
Page 1: Home (index.html)
Purpose

Welcome visitors and provide an overview of the symposium.

Content
  • College logo
  • Symposium banner image
  • Symposium name: TechNova 2026
  • Theme of the event
  • Date and venue
  • Brief introduction
  • Navigation menu to all pages
  • Highlights section
  • 500+ Participants
  • 15 Events
  • Cash Prizes
  • Industry Experts
Page 2: About Symposium (about.html)
Purpose

Provide detailed information about the event.

Content
  • Symposium objectives
  • Event vision and mission
  • Organizing department
  • Why students should participate
  • Benefits of participation
Page 3: Technical Events (technical.html)
Purpose

Display all technical competitions.

Content
Event 1: Paper Presentation

Present innovative research ideas.

Event 2: Web Design Contest

Build attractive websites.

Event 3: Coding Challenge

Solve programming problems.

Event 4: Project Expo

Showcase innovative projects.

For each event:

Event image

Description

Rules

Prize details

Page 4: Non-Technical Events (nontechnical.html)
Purpose

Display entertainment and fun events.

Content
Event 1: Photography
Event 2: Quiz Competition
Event 3: Treasure Hunt
Event 4: Gaming Tournament

For each event:

Description

Rules

Registration fee

Prize information

Page 5: Event Schedule (schedule.html)
Purpose

Display complete event timetable.

Content
  • Time
  • Event
  • Venue
  • 9:00 AM
  • Inauguration
  • Auditorium
  • 10:00 AM
  • Paper Presentation

  • Hall A
  • 3:00 PM
  • Project Expo
  • Exhibition Hall
  • 4:30 PM
  • Prize Distribution
  • Auditorium
Page 6: Registration (register.html)
Purpose

Allow students to register.

Form Fields
Personal Information
  • Full Name
  • College Name
  • Department
  • Year of Study
Contact Information
  • Email
  • Phone Number
Event Selection
  • Choose Technical Event
  • Choose Non-Technical Event
Additional Information
  • Address
  • Comments
Buttons
  • Submit
  • Reset
Page 7: Contact Us (contact.html)
Purpose

Provide communication details.

Content
  • Faculty Coordinator
  • Name
  • Email
  • Phone

  • Coordinator 1
  • Coordinator 2
  • Venue Address
  • Social Media Links
  • Instagram

  • Embedded College Location Image

CSS Requirements (Mandatory)
1. CSS Selectors
Use at least:
  • Element selector
  • Class selector
  • ID selector
  • Descendant selector
  • Pseudo-class (:hover)
  • Pseudo-element (::before or ::after)
2. Box Model

Demonstrate:

Margin

Padding

Border

Border-radius

Box-sizing

3. Typography
Use:
  • Font family
  • Font size
  • Font weight
  • Text alignment
  • Text transformation
  • Letter spacing
4. Colors and Backgrounds
Use:
  • Background colors
  • Background images
  • Gradient background (optional bonus)
5. Navigation Bar

Create a navigation menu with:

Hover effects

Active page highlighting

6. Layout using Flexbox

Use Flexbox for:

Navigation menu

Highlights section

Event cards

Contact section

7. CSS Grid

Use Grid layout for at least one section such as:

Technical Events

Non-Technical Events

Gallery

Highlights

8. Tables

Style the Event Schedule table with:

Borders

Alternate row colors

Hover effect

Header styling

9. Forms

Style the registration form using:

Labels

Input fields

Radio buttons/Checkboxes (optional)

Dropdown lists

Focus effect

Styled buttons

10. Positioning

Use at least one of:

Relative

Absolute

Fixed

Sticky

Example:
  • Sticky navigation bar
  • Fixed "Back to Top" button
11. Display Property
Use:
  • Block
  • Inline
  • Inline-block
12. Responsive Design

Use Media Queries for:

Mobile devices

Tablet devices

Desktop devices

13. Images

Apply:

Rounded corners

Shadows

Responsive sizing

14. CSS Effects

Use at least three:

Transition

Transform

Box-shadow

Text-shadow

Opacity

15. Footer

Create a common footer for every page containing:

Copyright

Quick links

Social media icons/text links

4. Learning Outcomes

  • Learned how to link an external stylesheet and use different CSS selectors (element, class, id, hover, ::after) to style a page.
  • Practiced layout techniques such as Flexbox, Grid, positioning and media queries to arrange content and make the site responsive.
  • Understood how keeping the same HTML and only adding CSS completely changes the look of a website.
